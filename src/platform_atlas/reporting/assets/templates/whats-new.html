What's New in 2.1

SSH got serious. ControlMaster is now production-hardened for jump hosts and CyberArk PSMP — shorter sockets, non-blocking checks, auto-open prompts. Plus compliance trends over time, password auth per node, environment drafts that survive Ctrl-C, and 122 rules.

Headline

The big ones

The features that change how you work day-to-day.

CLI

ControlMaster, hardened

The end of the jump-host headaches. Shorter socket paths (role-based names, never the full hostname) prevent bind: filename too long failures. In HA2, one socket per role — non-primary nodes never get their own SSH connection. Missing or stale sockets show a status table and prompt Proceed anyway? — no more hard blocks. The new env sockets command lets you inspect, clean, and open connections with MFA inline. And Atlas rechecks sockets right before capture catches anything that expired during a long setup session.

CLI

session trend

A new command that renders a compliance heat matrix — category pass rates across your sessions over time in one table. Supports --env, --all-envs, and --limit so you can scope it to a single environment or see drift across all of them. The fastest way to answer "has this environment been getting better or worse?"

CLI

horizon-atlas — a new default

Fresh installs now open into horizon-atlas: a deep ocean dark background with a bioluminescent blue-green primary — built for terminals where you spend hours. It replaces horizon-prism as the out-of-the-box theme. If your config already has an explicit theme value, nothing changes. The setup wizard now offers a theme picker at first-run so you can choose before the wizard even begins.

CLI + WebUI

Password-based SSH auth

Not every environment uses key-based SSH. The wizard and env edit now let you choose key or password per node. The password goes straight to your active credential backend — never written to the env file or a capture. The WebUI environment form mirrors this with the same per-node picker.

CLI

Environment drafts

The wizard saves a draft the moment you confirm the environment name. Bail out with Ctrl-C and nothing is lost — re-run env create <name> and you're offered resume or start over. env list marks incomplete environments with a ⚠ incomplete badge so nothing gets accidentally left half-finished.

CLI + WebUI

GW4 + GW5 together

Extended and SaaS environments can now pair a Gateway 4 API target with a Gateway 5 SSH or file node in a single audit — the gw4-gw5 gateway kind. Previously you had to choose one or the other and run separate sessions. The WebUI environment form and the CLI wizard both expose the combined picker.

Also new

More in this release

Individual node editingCLI

env edit now opens a sub-menu: edit a single node's fields, change capture scope, or replace the full topology — instead of running the whole topology wizard every time.

env sockets commandCLI

env sockets <name> with --clean or --open — inspect ControlMaster socket health, remove stale files, or open missing connections with MFA inline.

--log-days NCLI

Analyze the last N days of logs (1–30) on session run capture without having to calculate a --log-since date. Cannot be combined with --log-since.

Protocol-only nodesCLI

Mark a Redis node as protocol_only so SSH is never attempted — useful for managed services like Elasticache or MemoryDB. The HA2 wizard asks if Redis is a managed service.

env create --from-fileCLI

Create an environment from a JSON file, bypassing the wizard entirely — useful for scripted or templated deployments.

--skip-adapter-checkCLI

Skip the GitLab adapter version check during session run validate or session run all. Useful when the target environment has no outbound access to GitLab.

authSource advisoryCLI

A yellow banner appears when a MongoDB URI has credentials but no authSource parameter — the most common cause of auth failures on first connect.

control_persist_minutesCLI

New config field (default 60) replacing the hardcoded 10-minute ControlPersist duration. Tune it to match your MFA session length.

Reliability

Fixes & changes

MongoDB readWrite and readWriteAnyDatabase roles now satisfy the read-permission check. Previously only more permissive roles passed the rule.
GW5 file collector (Docker Compose / Helm) now runs for gw4-gw5 environments. The collector registration was checking kind == "gateway5" and silently skipped GW5 data when both gateways were selected.
GW4 API target always synthesized for gw4-gw5 environments. A GW5 topology node made self.deployment truthy and previously caused the GW4 collector to be silently dropped.
tier show gateway label and rows are now correct for gw4-gw5. The label now reads "Gateway 4 + Gateway 5" and both the GW4 API and GW5 entries appear correctly.
horizon-light theme: four capture prompts were invisible on light terminals. Confirm prompts were missing style=get_qstyle() and rendered in questionary's default colors against a white background.
IAG-007 severity lowered to info (was warning).
Pandas pipeline fully vectorized. All iterrows loops replaced with vectorized equivalents. Low-cardinality columns stored as pd.Categorical. Redundant DataFrame sort removed from HTML report render. All read_parquet calls now specify engine="pyarrow" explicitly.
